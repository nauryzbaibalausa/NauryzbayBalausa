6. Запуск Duckiematrix / Отчёт о технической проблеме
При попытке запуска Duckiematrix (команда dts matrix run --standalone --sandbox --verbose --browser) возникла техническая проблема. Из-за низкого качества и низкой скорости интернет-соединения, а также ограниченного объёма доступной памяти (8 ГБ ОЗУ и 10 ГБ на диске C:) загрузка необходимых компонентов и Docker-образов зависала и не могла завершиться. В результате система не смогла полностью загрузить и запустить симуляцию.

7. Вывод (Итоговый заключительный отчет)
В ходе выполнения работы были успешно установлены и настроены среда WSL 2 с Ubuntu и Docker Desktop на операционной системе Windows 11. Базовые этапы проверки виртуализации и работы Docker (команды wsl --status, docker --version, docker run hello-world) прошли успешно.
Однако этап запуска Duckiematrix выполнить до конца не удалось из-за технических ограничений: нехватки свободной памяти на диске/ОЗУ и нестабильного интернета, что блокировало скачивание тяжелых контейнеров и образцов.
